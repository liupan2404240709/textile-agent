# 文件上传功能使用说明

## 🎯 功能概述

用户现在可以上传 Word、Excel、PDF、TXT、Markdown 等格式的文件，结合提问一起交给大模型处理。

---

## 📋 支持的文件格式

- ✅ **Word 文档**: `.doc`, `.docx`
- ✅ **Excel 表格**: `.xls`, `.xlsx`
- ✅ **PDF 文档**: `.pdf`
- ✅ **文本文件**: `.txt`
- ✅ **Markdown**: `.md`

**文件大小限制**: 最大 50MB

---

## 🚀 使用步骤

### 1. 启动后端服务

```bash
cd E:\ai_project\ChatLLM-medical-main-papa
mvn spring-boot:run
```

### 2. 启动前端服务

```bash
cd papa-ui
npm run dev
```

### 3. 在聊天窗口中使用

1. 打开浏览器访问前端页面
2. 点击输入框旁边的 **📄 文件图标**
3. 选择要上传的文件（Word、Excel、PDF 等）
4. 在输入框中输入你的问题（可选，默认为"请分析这个文件的内容"）
5. 点击发送按钮

## 🔧 技术实现

### 后端

**核心组件**：
- `PapaController.uploadFileAndChat()` - 文件上传接口
- `PapaServiceImpl.uploadFileAndChat()` - 业务逻辑
- `Apache Tika` - 自动检测和提取文件内容

**处理流程**：
```
用户上传文件 
  ↓
Tika 解析文件内容
  ↓
构建组合提示词（文件内容 + 用户问题）
  ↓
调用大模型流式处理
  ↓
返回 AI 回答
```

### 前端

**核心组件**：
- `fileInputRef` - 文件选择器
- `handleFileSelected()` - 文件选择和验证
- `sendFileRequest()` - 发送文件到后端并接收流式响应

**UI 元素**：
- 文件上传按钮（Document 图标）
- 文件类型和大小验证
- 成功/失败提示

---

## ⚠️ 注意事项

1. **文件大小限制**：单个文件不超过 50MB
2. **内容长度限制**：如果文件内容超过 50,000 字符，会自动截取前 50,000 字符
3. **并发限制**：图片和文件不能同时上传（互斥）
4. **联网搜索**：文件上传时也支持开启"联网搜索"开关

## 🐛 常见问题

### Q1: 上传后提示"文件内容为空"？

**原因**：
- 文件可能是扫描件或图片型 PDF（需要 OCR）
- 文件格式损坏

**解决**：
- 确保文件是文本型 PDF 或标准 Office 文档
- 尝试重新保存文件

---

### Q2: 大文件处理很慢？

**原因**：
- 文件内容较多，解析和传输需要时间
- 大模型处理长文本较慢

**建议**：
- 尽量上传精简后的文档
- 耐心等待处理完成

---

### Q3: 如何查看文件是否上传成功？

**检查方法**：
1. 前端会显示 "📄 已选择文件：xxx" 的提示
2. 后端日志会显示：
   ```
   开始处理文件上传: fileName=xxx, fileType=pdf, fileSize=123456
   ✅ 文件内容提取成功，长度: 5000 字符
   🚀 开始调用大模型处理文件+提问
   ```
