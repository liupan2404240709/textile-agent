# 纺织设计师与纺织设计项目查询工具使用说明

## 概述
已为AI智能体创建了纺织设计师查询工具集（`TextileDesignQueryTools` 5 个工具 + `TextileReviewAppointmentTools` 3 个工具），
支持查询纺织设计师档案、纺织设计项目、纺织设计评审以及纺织设计评审会议预约。

## 工具列表

### 1. 查询纺织设计师档案
**工具名称：** `查询纺织设计师档案`
**功能：** 查询纺织设计师的基本信息、专业方向、资质证书、设计成果等
**使用场景：** 用户询问某位纺织设计师的信息时
**参数：** 纺织设计师姓名或编号（例如："张伟" 或 "TEX001"）

**示例对话：**
```
用户：查询张伟设计师的信息
智能体：[调用 查询纺织设计师档案("张伟")]
返回：完整的纺织设计师档案信息
```

### 2. 查询纺织设计项目
**工具名称：** `查询纺织设计项目`
**功能：** 查询纺织设计师的设计项目，包括项目名称、设计目标、阶段、验收标准、进度等
**使用场景：** 用户询问纺织设计师的项目安排或面料/花型/服装设计方案时
**参数：** 纺织设计师姓名或编号

**示例对话：**
```
用户：张伟负责哪些设计项目？
智能体：[调用 查询纺织设计项目("张伟")]
返回：纺织设计项目列表及详细信息
```

### 3. 查询纺织设计评审
**工具名称：** `查询纺织设计评审`
**功能：** 查询纺织设计师获得的纺织设计评审记录，包括多维度评分、评审内容、情感分析结果等
**使用场景：** 用户询问纺织设计师的设计能力、评审反馈时
**参数：** 纺织设计师姓名或编号

**示例对话：**
```
用户：张伟的设计评审结果怎么样？
智能体：[调用 查询纺织设计评审("张伟")]
返回：评审统计数据和详细评审列表
```

### 4. 查询纺织设计师完整信息
**工具名称：** `查询纺织设计师完整信息`
**功能：** 查询纺织设计师的完整信息，包括档案、设计项目、设计评审等全部内容
**使用场景：** 用户要求全面了解某位纺织设计师时
**参数：** 纺织设计师姓名或编号

**示例对话：**
```
用户：全面了解张伟设计师的信息
智能体：[调用 查询纺织设计师完整信息("张伟")]
返回：档案+设计项目+设计评审的完整信息
```

### 5. 按专业方向查询纺织设计师
**工具名称：** `按专业方向查询纺织设计师`
**功能：** 根据专业方向查询该方向下的所有纺织设计师列表
**使用场景：** 用户询问某个专业方向有哪些纺织设计师时
**参数：** 专业方向（例如："面料设计"、"服装设计"、"家纺设计"、"花型设计"、"印染工艺"）

**示例对话：**
```
用户：面料设计方向有哪些设计师？
智能体：[调用 按专业方向查询纺织设计师("面料设计")]
返回：面料设计方向纺织设计师列表
```

### 6. 预约纺织设计评审
**工具名称：** `预约纺织设计评审`
**功能：** 预约纺织设计评审会议；预约前会先查询排期并请用户确认
**参数：** 预约人姓名、身份证号、评审项目名称、日期、时间段、评审专家姓名

### 7. 取消纺织设计评审预约
**工具名称：** `取消纺织设计评审预约`
**功能：** 取消已存在的纺织设计评审预约记录

### 8. 查询评审排期
**工具名称：** `查询评审排期`
**功能：** 根据项目名称、日期、时间与评审专家查询是否还有排期

## 使用示例

### 场景1：查询单个纺织设计师信息
```
用户：我想了解一下张伟设计师的情况
智能体：好的，我来为您查询张伟的档案信息。
       [自动调用 查询纺织设计师档案("张伟")]
       返回查询结果并展示给用户
```

### 场景2：查询纺织设计师的项目安排
```
用户：张伟现在在做什么项目？
智能体：让我查询一下张伟的纺织设计项目。
       [自动调用 查询纺织设计项目("张伟")]
       返回纺织设计项目详情
```

### 场景3：查询纺织设计师的评审情况
```
用户：张伟的面料方案评审反馈如何？
智能体：我来查询一下张伟获得的纺织设计评审。
       [自动调用 查询纺织设计评审("张伟")]
       返回评审报告和统计数据
```

### 场景4：按专业方向查找纺织设计师
```
用户：你们这有做面料设计的设计师吗？
智能体：让我查询一下面料设计方向的纺织设计师。
       [自动调用 按专业方向查询纺织设计师("面料设计")]
       返回面料设计方向纺织设计师列表
```

### 场景5：预约纺织设计评审会议
```
用户：帮我预约周四下午的面料开发评审
智能体：[先调用 查询评审排期] → 与用户确认信息 → [调用 预约纺织设计评审]
```

## 数据说明

### 测试数据（已通过Java初始化器插入）
- **纺织设计师档案：** 张伟（面料设计）、李芳（家纺设计）等10位纺织设计师
- **纺织设计项目：** 每位设计师1-2个纺织设计项目
- **纺织设计评审：** 每条评审包含多维度评分和情感分析

### 返回信息格式
所有工具返回的信息都采用格式化输出，包含emoji图标，便于阅读：
- 📋 档案信息
- 📅 纺织设计项目
- ⭐ 纺织设计评审报告
- 🎯 专业方向查询

## 配置说明

### 工具注册
工具已在 `PapaAgent.java` 中注册：
```java
@AiService(
    wiringMode = EXPLICIT,
    streamingChatModel = "qwenStreamingChatModel",
    chatMemoryProvider = "chatMemoryProviderPapa",
    contentRetriever = "contentRetrieverPapa",
    toolProvider = "mcpToolProvider",
    tools = {"textileDesignQueryTools", "textileReviewAppointmentTools"}  // 纺织设计师查询工具 + 纺织设计评审预约工具
)
```

### 启动要求
1. 确保数据库已执行 `create_textile_design_tables.sql` 建表SQL
2. 重启Spring Boot应用，`TextileDesignerDataInitializer` 会自动插入测试数据
3. 智能体会自动识别并使用这些工具

## 技术实现

### 核心文件
- **工具类：** `TextileDesignQueryTools.java`、`TextileReviewAppointmentTools.java`
- **服务层：** `TextileDesignerService.java`、`TextileReviewAppointmentService.java`
- **实体类：** `TextileDesignerProfile.java`、`TextileDesignProject.java`、`TextileDesignReview.java`、`TextileReviewAppointment.java`
- **智能体配置：** `PapaAgent.java`

### 查询逻辑
1. 智能体识别用户意图
2. 自动选择合适的工具
3. 调用Service层查询数据库
4. 格式化返回结果给用户

## 注意事项
1. 工具支持通过姓名或编号（TEX 前缀）查询纺织设计师
2. 所有查询都经过Service层的业务逻辑处理
3. 评审数据包含情感分析结果（positive/neutral/negative）
4. 纺织设计项目包含进度跟踪和评审状态
5. 数据使用UTF-8编码，确保中文正确显示
