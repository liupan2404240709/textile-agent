# MCP Web Search 详细日志使用说明

## ✅ 已增强的日志功能

### 1. MCP 工具执行结果日志（新增）
**文件**: `McpToolExecutionLogger.java`

每次 MCP Web Search 工具执行时，会记录：
- 📤 **工具调用请求**：工具名称、工具ID、调用参数
- 📥 **工具返回结果**：完整返回内容、结果长度
- ❌ **错误信息**：如果有异常会详细记录

### 2. HTTP 层请求/响应日志
**位置**: `McpConfig.java`

智谱 Web Search API 的 HTTP 请求和响应会被自动记录（已开启）

### 3. LLM 对话日志
**文件**: `LlmConversationLoggingListener.java`

记录每次对话的请求和响应，包括：
- 请求消息数量和类型
- 工具调用请求详情
- 响应内容和 Token 使用情况

#### 1️⃣ **工具调用请求**
```

│ 工具 ID: xxx

│ 工具名称: web_search
│ 工具 ID: xxx

```

#### 3️⃣ **HTTP 请求日志**
搜索关键字：`HttpMcpTransport` 或 `Request:` / `Response:`

## ⚠️ 诊断幻觉问题

如果大模型仍然产生幻觉（时间不对、信息不对），请检查：

### 1. **MCP 是否真的被调用了？**
搜索日志：`📤 MCP 工具调用`
- 如果没有看到，说明模型没有决定调用工具
- 可能原因：System Prompt 不够明确

### 2. **MCP 返回了什么？**
搜索日志：`📥 MCP 工具结果`
- 查看完整返回内容
- 检查时间是否准确
- 检查信息是否相关

### 3. **MCP 返回的内容是否被模型正确使用？**
- 对比 MCP 返回的时间 vs 模型回答的时间
- 如果 MCP 返回正确但模型回答错误，说明模型忽略了工具结果

### 4. **HTTP 层是否有错误？**
搜索日志：`Response:` 或 `Error`
- 检查智谱 API 是否正常返回
- 检查是否有错误码

## 🔧 优化建议

### 如果发现问题是：

#### ❌ MCP 没有被调用
**解决**：增强 System Prompt
```java
// 在 buildSystemPrompt() 中添加强制要求
"当用户询问'今天'、'最新'等时效性问题时，必须调用 web_search 工具"
```

#### ❌ MCP 返回了但模型不用
**解决**：添加工具使用约束
```java
"你必须基于 web_search 工具返回的信息回答，不能编造"
"如果工具返回的信息与你的知识冲突，以工具返回为准"
```

#### ❌ MCP 返回的信息本身有误
**解决**：这是智谱 Web Search API 的问题
- 检查搜索 query 是否准确
- 考虑更换搜索 MCP 服务

## 📝 下一步操作

1. **重启后端服务**
   ```bash
   mvn spring-boot:run
   ```

2. **开启联网搜索**
   在前端页面点击"联网搜索"开关

3. **提问时效性问题**
   例如：“告诉我今天纺织行业行业新闻”

4. **查看后台日志**
   在 IDE 控制台或日志文件中搜索：
   - `🔧 [MCP 工具调用请求]`
   - `📥 MCP 工具结果`
   - `完整返回内容`

5. **对比分析**
   - MCP 返回的时间 vs 模型回答的时间
   - MCP 返回的信息 vs 模型回答的信息
   - 找出幻觉的根源

## 🎨 日志格式说明

所有 MCP 相关日志使用统一格式，便于识别：

```
┌─────────────────────────────────────────────────────────────────
│ 📤 MCP 工具调用 #1           ← 工具调用请求
├─────────────────────────────────────────────────────────────────
│ 工具名称: web_search
│ 工具参数: {"query": "xxx"}
└─────────────────────────────────────────────────────────────────

┌─────────────────────────────────────────────────────────────────
│ 📥 MCP 工具结果 #1           ← 工具返回结果
├─────────────────────────────────────────────────────────────────
│ 结果长度: 2500 字符
│ 📄 完整返回内容:
│ [完整内容...]
└─────────────────────────────────────────────────────────────────
```
